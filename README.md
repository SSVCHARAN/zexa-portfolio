# Portfolio Website

A premium portfolio website built to showcase my work in web design, UI/UX, and frontend development. The project focuses on modern design, smooth interactions, high performance, and responsive user experience.

## 🚀 Tech Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lenis Smooth Scroll
- MagicUI Components
- Vercel

## ✨ Features

- Responsive, mobile-first design
- Smooth scrolling and page animations
- Interactive UI with modern micro-interactions
- Performance-optimized assets
- SEO-friendly architecture
- Fast loading and Core Web Vitals optimization
